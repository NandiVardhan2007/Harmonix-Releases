## 📥 Download & Install

1. Open the **[latest release](https://github.com/NandiVardhan2007/Harmonix-Releases/releases/latest)**.
2. Download **`Harmonix-Android.apk`** from the *Assets* section.
3. On your phone, tap the file and allow **"Install unknown apps"** for your browser or file manager when prompted.
4. Follow the installer.

> Already have Harmonix installed? You don't need this page — the app checks here automatically and offers a one-tap in-app update whenever a new version ships.

## ✨ Features

- 🎧 **Multi-source streaming** — JioSaavn, Audius & YouTube Music in one library
- ⬇️ **Offline downloads** — save audio, cover art & synced lyrics for offline playback
- 🎤 **Real-time synced lyrics** — line-by-line, timed to the track
- 🎚️ **Built-in equalizer** — tune your sound with presets & custom bands
- 📃 **Custom & imported playlists** — build your own or import existing ones
- 🖤 **YouTube Music–style UI** — pure-black, art-forward, distraction-free
- 🔄 **Automatic updates** — the app fetches new versions straight from this repo

## 🔐 Verification & Safety

Every APK here is **signed with the official Harmonix release key** and built automatically by CI from source — no manual tampering. If your device warns about an unrecognized developer, that's expected for apps installed outside the Play Store; the signature guarantees each update genuinely comes from this project.
