## Windows Quick Install (PowerShell)

You can install or update Harmonix for Windows instantly with a single command. Open Windows PowerShell and run:

```powershell
irm https://raw.githubusercontent.com/NandiVardhan2007/Harmonix-Releases/main/install.ps1 | iex
```

The script automatically fetches the latest release, downloads `Harmonix-Setup.exe`, and opens the installation wizard.

## Download & Installation Guide

### Android (Mobile)
1. Download **`Harmonix-Android.apk`** from the [Latest Release](https://github.com/NandiVardhan2007/Harmonix-Releases/releases/latest).
2. Tap the downloaded file and allow **"Install unknown apps"** if prompted by Android.
3. Complete the setup. Future updates will be delivered seamlessly via the app's internal auto-updater.

### Windows (Desktop)
1. Download **`Harmonix-Setup.exe`** from the [Latest Release](https://github.com/NandiVardhan2007/Harmonix-Releases/releases/latest) or use the PowerShell one-liner above.
2. Run the installer and choose your destination directory.
3. Launch Harmonix from your Start Menu or Desktop shortcut.

## Core Features Across Android & Desktop

| Feature | Description |
|:---|:---|
| **Multi-Source HD Audio** | Aggregated 320kbps streams from JioSaavn (DES-ECB decrypted), Audius, and YouTube Music |
| **Synchronized Live Lyrics** | Dynamic auto-scrolling lyrics with tap-to-seek and millisecond offset timing calibration |
| **Multilingual AI Sing-Along** | Phonetic transliteration into 20 languages and Latin English romanization |
| **Camera QR Code Mobile Pairing** | Link your Desktop instance in 1 second by scanning Desktop's on-screen QR code from the Android app |
| **Strict Playback Auth** | Music streaming requires an active user account across all devices to protect library and history |
| **Cross-Device Session Management** | View active sessions across devices, monitor IPs and platforms, and remotely revoke sessions |
| **Parametric Equalizer** | Hardware-accelerated DSP with Bass Boost, Loudness Normalization (-14 LUFS), and presets |
| **Offline Storage** | High-bitrate audio downloads with embedded metadata tags and synced LRC files |
| **Automated Updates** | Both applications verify releases directly from this public repository for one-click updates |
